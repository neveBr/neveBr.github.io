Developer deep dive
Goal-oriented AI

A data-driven, goal-oriented planner: the agent reads its own stats and the world state to pick a goal, then searches available actions for one it can execute — each action has a cost, a reward, and a source/result pair — and picks whichever chain gets it there best. Here it wants to heal, spots an apple on a tree, finds a reachable vantage point and a zipline to get there, rides over, shoots the apple down, then walks over to pick it up.

Zone-based navigation

Custom pathfinding that handles both static geometry and moving platforms: scene colliders are merged into "zones" at bake time, and each navigator runs A* over the graph of zone links rather than raw world space. The path isn't always the shortest one — each character supplies its own edge weighting, so one might avoid the player's zone, another might steer around crowded paths, all on the same underlying graph.

ColorfulHierarchy (editor tool)

A small Unity editor extension that colors Hierarchy GameObjects — both the name text and the row background — for fast visual scanning of large, deeply nested scenes.
