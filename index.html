BubbleStars
Candivore / PixelPie · Unity Developer · 2023–2026

BubbleStars is a real-time PvP bubble shooter for mobile — 1v1 online matches, live events, and a full meta layer built around progression and rewards.

Two sides of the game
UI & meta

Seasonal game modes, live events, missions, inventory, progression, rewards, skins, player data, boosters, and level configs — all built as data-driven systems supporting live configuration and remote assets.

Core gameplay

Built on Photon Quantum's deterministic ECS, with multiple game modes supporting 1v1 or 2v2 play, a wide range of special bubbles, boosters and gadgets, and full bot support.

A closer look at the systems above
Goal-oriented AI

The AI is built around a data-driven, goal-oriented planning system. Agents evaluate their current state and the state of the world to determine which goals to pursue, then solve each goal by searching through available actions — each with its own requirements, cost, reward, and resulting state. Different enemies can run on the same system while behaving in completely different ways. In the video, the enemy needs to heal: it determines it needs the apple, that the apple can be shot down from a nearby platform, and that the platform is reachable via a zipline — then navigates there, knocks the apple down, and picks it up.

Zone-based navigation

Custom pathfinding that handles both static geometry and moving platforms: scene colliders are merged into "zones" at bake time, and each navigator runs A* over the graph of zone links instead of raw world space. The path isn't always the shortest one — each character supplies its own edge weighting, so one might avoid the player's zone while another steers around crowded paths, all on the same underlying graph.
